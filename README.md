SnakeWaterGun-Game

A simple command-line Snake-Water-Gun game built with C++. Players compete against the computer, and scores are tracked throughout the game.

Features

* Play against the computer
* Random computer choices
* Score tracking
* Multiple rounds
* Displays game rules at the start

Technologies Used

* C++
Concepts Practiced

* Variables
* User Input and Output
* If-Else Statements
* Loops
* Random Number Generation
* Conditional Logic
* Score Tracking
